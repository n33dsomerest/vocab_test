# Vocab Trainer

แอปฝึกศัพท์ภาษาอังกฤษสำหรับสอบศุลกากร — เว็บไซต์ static ไฟล์เดียว ไม่มี build step ไม่มี dependency

**เว็บ:** https://vocab-test-alpha.vercel.app

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `vocab_trainer.html` | ตัวแอปทั้งหมด (HTML + CSS + JS ฝังในไฟล์เดียว) |
| **`vocab.json`** | **คำศัพท์ทั้งหมด — แก้ไฟล์นี้เพื่อเพิ่ม/ลบคำ** |
| `vocab.schema.json` | schema สำหรับตรวจรูปแบบข้อมูลอัตโนมัติใน VS Code |
| `vercel.json` | ตั้งค่าเส้นทางบน Vercel |
| `README.md` | ไฟล์นี้ |

## วิธีเพิ่มคำใหม่

แก้ `vocab.json` แล้วเพิ่ม object ในอาร์เรย์ `words` **1 ชิ้นก็เสร็จ**

```json
{
  "word": "Scrutinize",
  "pos": "v.",
  "meaning": "ตรวจสอบอย่างละเอียด",
  "example": "Customs officers must scrutinize every document carefully.",
  "fill": "Customs officers must _____ every document carefully.",
  "group": "scrutinize"
}
```

### ฟิลด์

| ฟิลด์ | จำเป็น | ความหมาย |
|---|---|---|
| `word` | ✅ | คำศัพท์ภาษาอังกฤษ ขึ้นต้นพิมพ์ใหญ่ |
| `pos` | ✅ | ชนิดคำ เช่น `v.` `adj.` `n.` `adv.` |
| `meaning` | ✅ | ความหมายภาษาไทย |
| `example` | ✅* | ประโยคตัวอย่าง แสดงบนการ์ดระดับ 1 |
| `fill` | ✅* | ประโยคสำหรับเติมคำระดับ 3 **ต้องมี `_____` ตรงตำแหน่งที่จะแทนที่คำ** |
| `group` | – | ชื่อกลุ่ม ใช้สร้างตัวเลือกหลอกที่สับสนได้จริง |
| `phrase` | – | `true` = วลี ใช้เป็นตัวเลือกหลอกอย่างเดียว **ไม่ถูกสุ่มมาให้เรียน** |

\* จำเป็นสำหรับทุกคำ **ที่ไม่ได้ใส่ `"phrase": true`**

### กติกาสำคัญ

1. **ต้องไม่มีคำซ้ำ** (เทียบแบบไม่สนตัวพิมพ์ใหญ่/เล็ก) — ถ้าซ้ำแอปจะขึ้นข้อความบอก
2. **ช่องว่าง `_____` ต้องไม่ติดกับตัวอักษร** — ผิดแบบนี้: `Customs officers _____d the goods` ❌ ถูกแบบนี้: `Customs officers _____ the goods` ✅
3. **`fill` ต้องมี `_____` พอดี 1 จุด** และต้องเป็นคำที่เติมแล้วประโยคอ่านรู้เรื่อง
4. **คำที่มีช่องว่างในตัวเอง** (เช่น `Consist of`) ให้ใส่ `"phrase": true` — วลีใช้เป็นตัวเลือกหลอกอย่างเดียว ไม่เข้า SRS
5. **กลุ่มควรมี 4–5 คำ** — ถ้าน้อยกว่า 4 ระบบจะสุ่มตัวหลอกจากทั้งชุดแทน (ยังใช้ได้ แต่คุณภาพต่ำกว่า)

### ตัวอย่าง: เพิ่มคำใหม่ 1 คำพร้อมกลุ่ม

สมมติต้องการเพิ่มคำว่า **Mitigate** (ลดผลกระทบ) เข้าไปในกลุ่มเดียวกับ Comprise:

```json
{ "word": "Mitigate", "pos": "v.", "meaning": "ลดผลกระทบ",
  "example": "The new policy aims to mitigate the damage.",
  "fill": "The new policy aims to _____ the damage.",
  "group": "comprise" },

{ "word": "Comprise", "pos": "v.", "meaning": "ประกอบด้วย", "...": "..." }
```

ระบบจะเอาคำในกลุ่ม `comprise` มาสร้างตัวเลือกหลอกให้กันเองอัตโนมัติ

> **หมายเหตุ:** ตั้งแต่เวอร์ชันนี้ คำหนึ่งคำอยู่ได้**กลุ่มเดียว** (โค้ดเดิมอนุญาตให้อยู่ได้หลายกลุ่ม) ถ้าอยากให้คำเดียวกันเป็นตัวหลอกของอีกกลุ่มหนึ่ง ให้เพิ่มคำนั้นลงในกลุ่มนั้นซ้ำอีกครั้ง **ไม่ได้** — ให้สร้างคำใหม่แทน

## ตรวจสอบความถูกต้องก่อนบันทึก

- **VS Code:** เปิด `vocab.json` แล้วจะตรวจ schema ให้อัตโนมัติ (แดง = ผิด)
- **ในเบราว์เซอร์:** ถ้าข้อมูลผิดรูปแบบ หน้าเว็บจะขึ้นข้อความบอกเหตุผล เช่น `vocab.json: คำ "X" ขาดฟิลด์ "fill"`

## การเปิดใช้งานบนเครื่อง

เพราะแอปโหลดข้อมูลด้วย `fetch()` **ต้องเปิดผ่านเว็บเซิร์ฟเวอร์** ดับเบิลคลิกไฟล์ HTML ตรง ๆ จะไม่ทำงาน (เบราว์เซอร์บล็อกการอ่านไฟล์ข้างเคียง)

```bash
npx serve .
# แล้วเปิด http://localhost:3000
```

## Deploy

```bash
vercel --prod --yes
```

โปรเจกต์เชื่อมกับ scope `mougaw-s` ชื่อ `vocab-test`

## การทำงานของระบบ SRS

4 ระดับ ผู้เรียนเลื่อนขึ้นทีละระดับเมื่อตอบถูก 2 ครั้งติดต่อกัน ตอบผิดจะถอยลง 1 ระดับ

| ระดับ | แท็บ | วิธีฝึก |
|---|---|---|
| 1 | 📇 การ์ด | พลิกการ์ดดูความหมาย + ประเมินตัวเอง |
| 2 | ✅ ตัวเลือก | เลือกความหมายที่ถูกต้องจาก 4 ข้อ |
| 3 | ✏️ เติมคำ | เติมคำลงช่องว่างจากคลังคำ (สูงสุด 4 ช่อง) |
| 4 | ⌨️ สะกดคำ | พิมพ์คำศัพท์จากความหมายไทย |
| 5 | — | จบแล้ว ไม่มีแท็บ (ถอยกลับไม่ได้) |

ความคืบหน้าเก็บใน `localStorage` ของเบราว์เซอร์ **ยังไม่มีปุ่ม reset หรือ export** — ถ้าล้าง site data ความคืบหน้าจะหาย
